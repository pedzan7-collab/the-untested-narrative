# The Untested Narrative

Evidence. Due process. Accountability.

A blog version of [The Untested Narrative](https://www.facebook.com/profile.php?id=61596604298667) Facebook page: evidence-led writing on wrongful convictions, disputed allegations and failures of justice.

## What's here

- `index.html` – the whole site (posts, topics, quiz, sources library, about page). No build step.
- `media/` – images, logo and the compressed explainer video.

## Adding a post

Posts live in the `POSTS` list near the top of the script in `index.html`. Copy an existing entry, give it a new `slug` and the next `file` number, and put any images in `media/`.

## Viewing locally

Open `index.html` in a browser.
